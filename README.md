# Python Programming Assignment

**Name:** Karanki Mahesh

## Programs Included

1. Find numbers between 2000 and 3200 that are divisible by 7 but are not multiples of 3.
2. Convert a list of characters into a string.
3. Generate a dictionary containing numbers from 1 to `n` and their squares.

## Language

Python 3

## How to Run

Run `assignment.py` using Python 3.

For Program 3, enter the required number when prompted.

### Example

Input:
```text
5
```

Output:
```text
{1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```
