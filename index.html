1. Numbers Divisible by 7

Find all numbers between 2000 and 3200 which are divisible by 7 but are not multiples of 3.

Click the button to run the program.
# Python Program 1 numbers = [] for i in range(2000, 3201): if i % 7 == 0 and i % 3 != 0: numbers.append(str(i)) print(",".join(numbers))

3. Generate Dictionary of Squares

Enter an integer n to generate a dictionary containing numbers from 1 to n and their squares.

Enter a number and click the button.
# Python Program 3 n = int(input("Enter a number: ")) result = {} for i in range(1, n + 1): result[i] = i * i print(result)
