1. Numbers Divisible by 7

Write a program which will find all such numbers which are divisible by 7 but are not a multiple of 3, between 2000 and 3200. Print the output as a comma-separated sequence.

Python Code

numbers = []

for i in range(2000, 3201):
    if i % 7 == 0 and i % 3 != 0:
        numbers.append(str(i))

print(",".join(numbers))

Output

2002,2009,2016,2023,2030,2037,2044,...

3. Generate a Dictionary

With a given integral number n, write a program to generate a dictionary that contains (i, i*i).

Python Code

n = int(input("Enter a number: "))

result = {}

for i in range(1, n + 1):
    result[i] = i * i

print(result)
